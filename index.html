Experimental details & diagnostic scope

Scope: The intervention establishes gallery sensitivity, not a sole causal effect of cue prevalence.

The diagnostic uses a predefined 79-cue semantic catalog spanning clothing and footwear color, garment and footwear type, sleeve length, carried items, worn accessories, and clothing patterns. Cues are matched by deterministic, slot-aware lexical rules that favor precision.

After compatibility pruning, 2,613 unordered cue-pair cases form the frozen master case set. Each eligible case-query instance can produce five indexed paired trials with gallery size 300, fixed seed 42, and a cue-density-shift admission threshold of 0.1.

An off-the-shelf CLIP model is used only as a label-free construction instrument for cue-directed distractors and neutral fillers. The evaluated retrievers do not construct or admit their own trials.

Confidence intervals are computed with 1,000 query-cluster bootstrap resamples, preserving all trials associated with each sampled query.

METHOD

GATE: Gallery-Aware Text Enrichment

GATE keeps the host retriever frozen, reads structured evidence from the current unlabeled gallery, and applies a controlled residual update to the text query.

Gallery evidence → Query-conditioned reasoning → Residual enrichment → Complete-gallery retrieval

04 / Discussion

What does GATE teach us beyond GATE?

GATE ⊂ T-TBPS
UNDERSTANDING THE MECHANISM High-ranked mistakes can still be useful evidence.

The frozen retriever's current competition reveals plausible alternatives the query must distinguish from; evidence need not be treated as predicted positives to be useful.

#1#2#3…#M
CURRENT COMPETITION
COMPETITION AS SIGNAL The useful signal is the structure of plausible alternatives, not only likely positives.
BEYOND ONE METHOD T-TBPS leaves evidence and reasoning open.

GATE fixes one choice of gallery evidence and one reasoning mechanism; the setting itself prescribes neither.
