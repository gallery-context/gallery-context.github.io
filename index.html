The Gallery as Context

Transductive Text-Based Person Search

What makes a textual cue useful depends on who else is in the gallery.

3 benchmarks 5 frozen retrievers 624,440 paired interventions

The core question

A hidden assumption in text-based person search

Standard TBPS encodes a text description before observing the current candidate gallery. That makes the query representation fixed, even though a cue such as clothing color, carried objects, or footwear may become more or less discriminative depending on the alternatives in front of it.

Should query construction always remain independent of the search space?

Same query, different gallery

The useful cue can change with the candidate population

Consider the same description: a person wearing a black jacket and carrying a bag. In one gallery, the jacket may be rare. In another, many distractors share that jacket, so the bag or another local cue becomes more useful.

Controlled gallery intervention

Keep the retrieval problem fixed, swap the cue-directed distractors

The diagnostic creates paired galleries for an eligible query that mentions two cues. Each pair preserves the query, target identity, complete positive image set, neutral fillers, gallery size, and evaluated retriever. Only an equal-sized distractor subset is swapped to emphasize one query-mentioned cue versus the other.

Technical details of the diagnostic protocol

The diagnostic uses a predefined 79-cue semantic catalog spanning clothing and footwear color, garment and footwear type, sleeve length, carried items, worn accessories, and clothing patterns. Cues are matched by deterministic, slot-aware lexical rules that favor precision.

After compatibility pruning, 2,613 unordered cue-pair cases form the frozen master case set. Each eligible case-query instance can produce five indexed paired trials with gallery size 300, fixed seed 42, and a cue-density-shift admission threshold of 0.1.

An off-the-shelf CLIP model is used only as a label-free construction instrument for cue-directed distractors and neutral fillers. The evaluated retrievers do not construct or admit their own trials.

Confidence intervals are computed with 1,000 query-cluster bootstrap resamples, preserving all trials associated with each sampled query.

Diagnostic result

Frozen retrievers are sensitive to cue-directed gallery composition

Across three benchmarks and five frozen retrievers, the paired cue-swap protocol yields 624,440 gallery interventions and more than 3.1 million retriever-trial evaluations. Top-1 correctness changes in 2.84% to 15.66% of paired trials.

15 / 15 dataset x retriever combinations exhibit non-zero decision sensitivity

Every 95% query-cluster bootstrap interval remains above zero; the smallest lower bound is 2.56%.

Interpretation matters: this demonstrates sensitivity to cue-directed gallery composition. Because the swapped distractor subsets also contain different images and identities, it is not a sole-cause estimate of cue prevalence.

From TBPS to T-TBPS

Move the information boundary

T-TBPS is the inference setting. It allows the current unlabeled gallery to participate in query construction before final retrieval. GATE is one instantiation of that setting, not a synonym for it.

Introducing GATE

Gallery-Aware Text Enrichment

GATE is a plug-and-play framework that keeps the base TBPS retriever frozen. It separates gallery evidence construction from query-conditioned gallery reasoning, then returns an enriched query for complete-gallery retrieval.

Observe Construct evidence Reason Correct Retrieve

Step 1 - Observe the gallery

Use the frozen ranking as the current competition

The base retriever ranks the gallery normally. GATE gathers an ordered Top-M candidate set as query-specific context. These candidates are not pseudo-labels and not a final candidate restriction; hard negatives can be informative evidence about the search space.

Step 2 - Construct gallery evidence

Cache complementary evidence slots for each gallery image

Evidence Providers expose structured, label-free views of each candidate. The reported experiments use a single-slot Global Semantic provider for the main model, and evaluate spatial and gallery-relative providers in ablations.

Provider outputs are deterministic and parameter-free. The Evidence Cache is constructed once for the current gallery and reused across queries.

Step 3 - Reason with QCRS-Mixer

Preserve rank x slot structure while reasoning

The Query-Conditioned Rank-Slot Mixer treats the evidence tensor as organized information, not an unordered pile. The slot axis integrates complementary evidence for one candidate; the rank axis compares the same evidence type across competing candidates.

Step 4 - Residual query enrichment

Correct the frozen query instead of replacing it

GATE fuses the gallery context with the original frozen query representation and predicts a residual correction. The identity path keeps the original query visible, so enrichment is an additive correction rather than a reconstruction from scratch.

Step 5 - Retrieve over the complete gallery

GATE is not Top-M re-ranking

Top-M is used to gather context. After enrichment, every gallery image remains eligible, the enriched query is evaluated against the complete gallery, no test-gallery identity labels are used, and no test-time gallery optimization is performed.

Technical details of GATE training and inference

The main configuration uses the single-slot Global Semantic provider. Ablations test vertical and horizontal 12-region layouts, a 3 x 3 grid layout, centroid evidence, and image-to-centroid residual evidence.

The reported configuration gathers M = 64 candidates, uses a one-block QCRS-Mixer with width 256, and applies a static residual scale gamma = 0.3. The training temperature is 0.02.

Added trainable parameters for the single-slot Global configuration are reported as 1,957,922, about 1.24% relative to the mean CLIP-baseline parameter count used in the analysis.

GATE is optimized for 60 epochs with Adam, learning rate 1e-5, weight decay 4e-5, batch size 256, cosine scheduling, five warm-up epochs, and deterministic seed 1.

Main benchmark results

The strongest GATE configuration leads all three benchmarks

GATE attached to ITSELF reports the strongest in-domain results across CUHK-PEDES, ICFG-PEDES, and RSTPReid. The page shows R@1 and mAP beside the frozen base retriever so the gain is visible rather than implied.

Average gains across the five base retrievers are +0.44 R@1 / +2.53 mAP on CUHK-PEDES, +0.72 / +4.33 on ICFG-PEDES, and +1.50 / +2.27 on RSTPReid.

Improvements across base retrievers

Gallery-aware enrichment is not tied to one host model

CLIP, IRRA, RDE, DM-Adapter, and ITSELF all improve when the frozen retriever is paired with GATE. Both R@1 and mAP improve in all 15 in-domain base-retriever and benchmark combinations.

Cross-domain generalization

The benefit persists when the target benchmark is unseen

Source-trained retrievers and their GATE modules transfer directly to a new target benchmark. GATE constructs a new cache from the unlabeled target gallery, without target labels, pseudo-labels, prompt updates, parameter updates, or target-set optimization.

30 / 30 base-retriever x transfer settings improve in both R@1 and mAP

What matters? Evidence ablations

More evidence is not automatically better

Semantic, spatial, and gallery-relative providers can all help, but the best provider varies by dataset and metric. Combining additional providers does not monotonically outperform the strongest individual provider.

What matters? Reasoning structure ablations

Seeing gallery evidence is not enough

MeanPool gives little mAP improvement, and Flat-MLP is stronger but remains below the complete QCRS-Mixer across the three benchmark evaluations. The complete QCRS-Mixer reports the best R@1 on all three benchmarks and the best mAP on two.

What GATE is - and is not

A concise checklist

GATE is

  • gallery-aware query enrichment
  • built on a frozen base retriever
  • label-free with respect to the test gallery
  • complete-gallery retrieval after enrichment
  • a plug-in realization of T-TBPS

GATE is not

  • pseudo-labeling
  • test-time optimization
  • a replacement for the base retriever
  • Top-M re-ranking
  • dependent on test-gallery identity labels

Beyond GATE

The broader T-TBPS design space

GATE demonstrates one way to exploit the extra inference context allowed by T-TBPS. Future methods can vary what gallery evidence is exposed and how a query reasons over that evidence.

Limitations

Where the setting applies most naturally

Gallery availability

The current unlabeled gallery must be available before final retrieval.

Gallery dynamics

The setting is most natural for fixed or slowly changing galleries, and less direct for fully streaming galleries.

Diagnostic scope

The cue-swap diagnostic establishes sensitivity to cue-directed gallery composition, but does not show that every query benefits equally.

Inference boundary

T-TBPS intentionally changes standard TBPS by letting the current unlabeled target gallery inform query construction.

Closing takeaway

The gallery is not only the destination of retrieval. It can be a source of context for deciding how the query should search.
