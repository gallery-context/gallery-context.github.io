TL;DR

We study gallery-aware query construction for text-based person search. A controlled diagnostic finds reproducible sensitivity to cue-directed gallery composition, motivating T-TBPS and its GATE instantiation.

Research story

From Observation to Method

If the gallery changes what makes a description discriminative, why construct the query in isolation? We trace this observation from controlled evidence, to the T-TBPS setting, to GATE as a plug-and-play realization.

Retrieval decisions are sensitive to gallery composition

Under controlled cue-directed gallery interventions, changing part of the distractor population can alter Top-1 correctness while the query and target are kept fixed.

T-TBPS makes query construction gallery-aware

The current unlabeled gallery can inform how the text query is represented before retrieval over the complete gallery.

The base retriever can stay frozen

GATE realizes this setting through gallery-aware query enrichment while leaving the underlying TBPS retriever unchanged.

DIAGNOSTIC

Should TBPS Queries Be Gallery-Independent?

The overview suggests that the same description can become more or less discriminative depending on its competitors. We now test whether this sensitivity can be observed systematically under controlled gallery interventions.

INTERPRETATION

What does the diagnostic establish?

Retrieval decisions are measurably sensitive to cue-directed changes in gallery composition, even when the query, target, positives, gallery size, and evaluated retriever are held fixed.

This establishes gallery sensitivity, not a sole causal effect of cue prevalence: the swapped subsets necessarily contain different distractor images and identities.

Experimental protocol

The diagnostic uses a predefined 79-cue semantic catalog spanning clothing and footwear color, garment and footwear type, sleeve length, carried items, worn accessories, and clothing patterns. Cues are matched by deterministic, slot-aware lexical rules that favor precision.

After compatibility pruning, 2,613 unordered cue-pair cases form the frozen master case set. Each eligible case-query instance can produce five indexed paired trials with gallery size 300, fixed seed 42, and a cue-density-shift admission threshold of 0.1.

An off-the-shelf CLIP model is used only as a label-free construction instrument for cue-directed distractors and neutral fillers. The evaluated retrievers do not construct or admit their own trials.

Confidence intervals are computed with 1,000 query-cluster bootstrap resamples, preserving all trials associated with each sampled query.

The current gallery is therefore not merely a retrieval pool; it contains information about what is discriminative for the current search problem.

From TBPS to T-TBPS

T-TBPS lets the current unlabeled gallery inform query construction before final retrieval. GATE is one realization of that setting, not a synonym for it.

Analysis

The ablations separate the value of gallery evidence from the value of structured query-conditioned reasoning, then situate GATE inside a broader T-TBPS design space.

Evidence ablations

More evidence is not automatically better

Semantic, spatial, and gallery-relative providers can all help, but the best provider varies by dataset and metric. Combining additional providers does not monotonically outperform the strongest individual provider.

Reasoning structure ablations

Seeing gallery evidence is not enough

MeanPool gives little mAP improvement, and Flat-MLP is stronger but remains below the complete QCRS-Mixer across the three benchmark evaluations.

Boundary conditions

What GATE is - and is not

GATE is

  • gallery-aware query enrichment
  • built on a frozen base retriever
  • label-free with respect to the test gallery
  • complete-gallery retrieval after enrichment
  • a plug-in realization of T-TBPS

GATE is not

  • pseudo-labeling
  • test-time optimization
  • a replacement for the base retriever
  • Top-M re-ranking
  • dependent on test-gallery identity labels

Beyond GATE

The broader T-TBPS design space

GATE demonstrates one way to exploit the extra inference context allowed by T-TBPS. Future methods can vary what gallery evidence is exposed and how a query reasons over that evidence.

Scope

Limitations and Takeaway

T-TBPS intentionally changes the inference information boundary by using the current unlabeled target gallery. That opens useful context, but it also defines where the setting applies most naturally.

Gallery availability

The current unlabeled gallery must be available before final retrieval.

Gallery dynamics

The setting is most natural for fixed or slowly changing galleries, and less direct for fully streaming galleries.

Diagnostic scope

The cue-swap diagnostic establishes sensitivity to cue-directed gallery composition, but does not show that every query benefits equally.

Inference boundary

T-TBPS intentionally changes standard TBPS by letting the current unlabeled target gallery inform query construction.

Closing takeaway

The gallery is not only the destination of retrieval. It can be a source of context for deciding how the query should search.
