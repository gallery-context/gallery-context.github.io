The Gallery as Context: Transductive Text-Based Person Search

arXiv Code BibTeX

TL;DR

We study gallery-aware query construction for text-based person search. A controlled diagnostic finds reproducible sensitivity to cue-directed gallery composition, motivating T-TBPS and its GATE instantiation.

Research story

Highlights

Retrieval decisions are sensitive to gallery composition

Under controlled cue-directed gallery interventions, changing part of the distractor population can alter Top-1 correctness while the query and target are kept fixed.

T-TBPS makes query construction gallery-aware

The current unlabeled gallery can inform how the text query is represented before retrieval over the complete gallery.

The base retriever can stay frozen

GATE realizes this setting through gallery-aware query enrichment while leaving the underlying TBPS retriever unchanged.

Inference setting

From TBPS to T-TBPS

T-TBPS lets the current unlabeled gallery inform query construction before final retrieval. GATE is one realization of that setting, not a synonym for it.

Motivation and diagnostic

Why the Gallery Matters

The central assumption being challenged is simple: should query construction always remain independent of the search space? The diagnostic story moves from intuition to controlled evidence.

different competitors controlled swap measurable decision sensitivity

Same query, different gallery

A useful cue can depend on the candidate population

Consider the same description: a person wearing a black jacket and carrying a bag. In one gallery, the jacket may be rare. In another, many distractors share that jacket, so the bag or another local cue becomes more informative.

Controlled gallery intervention

Keep the retrieval problem fixed, swap cue-directed distractors

The paired cue-swap diagnostic preserves the query, target identity, complete positive image set, neutral fillers, gallery size, and evaluated retriever. Only an equal-sized distractor subset is swapped to emphasize one query-mentioned cue versus the other.

15 / 15 dataset x retriever combinations exhibit non-zero decision sensitivity

Across 3 benchmarks and 5 frozen retrievers, the protocol yields 624,440 paired gallery interventions and more than 3.1 million retriever-trial evaluations. Top-1 correctness Flip Rate ranges from 2.84% to 15.66%.

Interpretation matters: this demonstrates sensitivity to cue-directed gallery composition. Because the swapped distractor subsets also contain different images and identities, it is not a sole-cause estimate of cue prevalence.

Technical details of the diagnostic protocol

The diagnostic uses a predefined 79-cue semantic catalog spanning clothing and footwear color, garment and footwear type, sleeve length, carried items, worn accessories, and clothing patterns. Cues are matched by deterministic, slot-aware lexical rules that favor precision.

After compatibility pruning, 2,613 unordered cue-pair cases form the frozen master case set. Each eligible case-query instance can produce five indexed paired trials with gallery size 300, fixed seed 42, and a cue-density-shift admission threshold of 0.1.

An off-the-shelf CLIP model is used only as a label-free construction instrument for cue-directed distractors and neutral fillers. The evaluated retrievers do not construct or admit their own trials.

Confidence intervals are computed with 1,000 query-cluster bootstrap resamples, preserving all trials associated with each sampled query.

Method

How GATE Works

GATE is one realization of T-TBPS: it keeps the base retriever frozen, builds label-free evidence from the current gallery, reasons over rank x slot structure, enriches the query residually, and retrieves over the complete gallery.

01

Observe the gallery

The frozen retriever ranks the gallery normally. GATE gathers an ordered Top-M candidate set as query-specific context; these candidates are current competition, not pseudo-labels.

02

Construct evidence

Evidence Providers expose complementary, label-free views of gallery candidates. Provider outputs are deterministic and parameter-free; the Evidence Cache is constructed once for the current gallery and reused.

03

Reason over rank x slot structure

The Query-Conditioned Rank-Slot Mixer keeps the evidence tensor organized. The slot axis integrates complementary evidence for one candidate; the rank axis compares the same evidence type across competing candidates.

04

Enrich the query residually

GATE fuses gallery context with the original frozen query representation and predicts a residual correction. The identity path keeps the original query visible.

05

Retrieve over the complete gallery

GATE is not Top-M re-ranking. Top-M gathers context; after enrichment, every gallery image remains eligible, with no test-gallery identity labels or test-time gallery optimization.

Technical details of GATE training and inference

The main configuration uses the single-slot Global Semantic provider. Ablations test vertical and horizontal 12-region layouts, a 3 x 3 grid layout, centroid evidence, and image-to-centroid residual evidence.

The reported configuration gathers M = 64 candidates, uses a one-block QCRS-Mixer with width 256, and applies a static residual scale gamma = 0.3. The training temperature is 0.02.

Added trainable parameters for the single-slot Global configuration are reported as 1,957,922, about 1.24% relative to the mean CLIP-baseline parameter count used in the analysis.

GATE is optimized for 60 epochs with Adam, learning rate 1e-5, weight decay 4e-5, batch size 256, cosine scheduling, five warm-up epochs, and deterministic seed 1.

Quantitative evidence

Results

Results are reported beside the relevant frozen host retriever, across base models, and under cross-domain transfer. The emphasis is on scientific comparison, not headline counters.

Main benchmark results

The strongest GATE configuration leads all three benchmarks

GATE attached to ITSELF reports the strongest in-domain results across CUHK-PEDES, ICFG-PEDES, and RSTPReid. R@1 and mAP are shown beside the frozen base retriever so the gain is visible rather than implied.

Average gains across the five base retrievers are +0.44 R@1 / +2.53 mAP on CUHK-PEDES, +0.72 / +4.33 on ICFG-PEDES, and +1.50 / +2.27 on RSTPReid.

Across base retrievers

Gallery-aware enrichment is not tied to one host model

CLIP, IRRA, RDE, DM-Adapter, and ITSELF all improve when the frozen retriever is paired with GATE. Both R@1 and mAP improve in all 15 in-domain base-retriever and benchmark combinations.

Cross-domain generalization

The benefit persists when the target benchmark is unseen

Source-trained retrievers and their GATE modules transfer directly to a new target benchmark. GATE constructs a new cache from the unlabeled target gallery, without target labels, pseudo-labels, prompt updates, parameter updates, or target-set optimization.

30 / 30 base-retriever x transfer settings improve in both R@1 and mAP

Analysis

The ablations separate the value of gallery evidence from the value of structured query-conditioned reasoning, then situate GATE inside a broader T-TBPS design space.

Evidence ablations

More evidence is not automatically better

Semantic, spatial, and gallery-relative providers can all help, but the best provider varies by dataset and metric. Combining additional providers does not monotonically outperform the strongest individual provider.

Reasoning structure ablations

Seeing gallery evidence is not enough

MeanPool gives little mAP improvement, and Flat-MLP is stronger but remains below the complete QCRS-Mixer across the three benchmark evaluations.

Boundary conditions

What GATE is - and is not

GATE is

  • gallery-aware query enrichment
  • built on a frozen base retriever
  • label-free with respect to the test gallery
  • complete-gallery retrieval after enrichment
  • a plug-in realization of T-TBPS

GATE is not

  • pseudo-labeling
  • test-time optimization
  • a replacement for the base retriever
  • Top-M re-ranking
  • dependent on test-gallery identity labels

Beyond GATE

The broader T-TBPS design space

GATE demonstrates one way to exploit the extra inference context allowed by T-TBPS. Future methods can vary what gallery evidence is exposed and how a query reasons over that evidence.

Scope

Limitations and Takeaway

T-TBPS intentionally changes the inference information boundary by using the current unlabeled target gallery. That opens useful context, but it also defines where the setting applies most naturally.

Gallery availability

The current unlabeled gallery must be available before final retrieval.

Gallery dynamics

The setting is most natural for fixed or slowly changing galleries, and less direct for fully streaming galleries.

Diagnostic scope

The cue-swap diagnostic establishes sensitivity to cue-directed gallery composition, but does not show that every query benefits equally.

Inference boundary

T-TBPS intentionally changes standard TBPS by letting the current unlabeled target gallery inform query construction.

Closing takeaway

The gallery is not only the destination of retrieval. It can be a source of context for deciding how the query should search.
