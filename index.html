TL;DR

We study gallery-aware query construction for text-based person search. A controlled diagnostic finds reproducible sensitivity to cue-directed gallery composition, motivating T-TBPS and its GATE instantiation.

Research story

From Observation to Method

If the gallery changes what makes a description discriminative, why construct the query in isolation? Keep the description and target fixed, change only the surrounding competitors, and the value of each cue changes with the gallery.

DIAGNOSTIC

Should TBPS Queries Be Gallery-Independent?

The overview suggests that the same description can become more or less discriminative depending on its competitors. We test that idea directly by changing only a cue-directed subset of distractors while keeping the retrieval problem fixed.

EMPIRICAL SIGNAL

Gallery sensitivity appears in every evaluated dataset × retriever combination.

Across three benchmarks and five frozen retrievers, the diagnostic comprises 624,440 paired gallery interventions and >3.1M retriever-trial evaluations.

WHAT THIS ESTABLISHES

The gallery contains information about what is discriminative for the current search.

Retrieval decisions are measurably sensitive to cue-directed gallery changes even when the query, target, positives, gallery size, and evaluated retriever are held fixed.

WHAT THIS DOES NOT CLAIM

This establishes gallery sensitivity, not a sole causal effect of cue prevalence: the swapped subsets necessarily contain different distractor images and identities.

Experimental protocol and exact Flip Rates

The diagnostic uses a predefined 79-cue semantic catalog spanning clothing and footwear color, garment and footwear type, sleeve length, carried items, worn accessories, and clothing patterns. Cues are matched by deterministic, slot-aware lexical rules that favor precision.

After compatibility pruning, 2,613 unordered cue-pair cases form the frozen master case set. Each eligible case-query instance can produce five indexed paired trials with gallery size 300, fixed seed 42, and a cue-density-shift admission threshold of 0.1.

An off-the-shelf CLIP model is used only as a label-free construction instrument for cue-directed distractors and neutral fillers. The evaluated retrievers do not construct or admit their own trials.

Confidence intervals are computed with 1,000 query-cluster bootstrap resamples, preserving all trials associated with each sampled query.

GATE keeps the host TBPS retriever frozen, uses the current unlabeled gallery as query-specific context, and predicts a controlled residual correction before retrieving over the complete gallery.

Why this matters

The first scan reveals what the gallery is currently confusing with the query. GATE does not guess this competition in advance — it reads it from the live retrieval result.

  • Complete-gallery first pass. Candidate selection comes directly from the frozen host retriever.
  • Ordered context. Rank carries information, so GATE keeps the Top-M as an ordered list.
  • Not pseudo-labeling. Top-M images are context, not assumed positives.
  • Not final retrieval. Images outside Top-M still remain eligible later.

05 / RETRIEVE

Use the enriched query for a second complete-gallery search

The Top-M list was only an evidence interface. Final retrieval still scores every gallery image, so GATE stays faithful to the full-gallery TBPS objective rather than collapsing into Top-M re-ranking.

≠
FINAL SEARCH SPACEComplete gallery
Retrieval role split

The first pass only reveals context. The second pass is the actual answer, and it scores all gallery images with the enriched query still anchored by the original host signal.

  • Two scans, two roles. One scan gathers context; the second produces the final ranking.
  • Full-gallery inference. Top-M never limits the final candidate set.
  • No test labels. There are no gallery identity labels, pseudo-labels, or target-set optimization at inference time.
  • Host-compatible. The enriched query stays in the same retrieval space as the original TBPS retriever.
Show the exact formulation
Complete-gallery inference score

sGATE(q,j) = ((1 − η)uq + ηũq)Taj, evaluated for every gallery image j = 1 ... Ng.

GATE IS NOT TOP-M RE-RANKING.Top-M is only the interface used to gather evidence. Final retrieval still ranks the full gallery.

Interpretation

Analysis

The ablations ask two complementary questions: which gallery evidence is useful, and how should that evidence be reasoned over? The answer is not “use more features,” but “use the right context while preserving its structure.”

Scope

Limitations and Takeaway

T-TBPS intentionally changes the inference information boundary by using the current unlabeled target gallery. That opens useful context, but it also defines where the setting applies most naturally.

Gallery availability

The current unlabeled gallery must be available before final retrieval.

Gallery dynamics

The setting is most natural for fixed or slowly changing galleries, and less direct for fully streaming galleries.

Diagnostic scope

The cue-swap diagnostic establishes sensitivity to cue-directed gallery composition, but does not show that every query benefits equally.

Inference boundary

T-TBPS intentionally changes standard TBPS by letting the current unlabeled target gallery inform query construction.

Closing takeaway

The gallery is not only the destination of retrieval. It can be a source of context for deciding how the query should search.
